# Участие в проекте

Для сообщения об ошибке не нужно знать Swift: создайте [обращение](https://github.com/eugggeneee/journal/issues/new/choose), опишите шаги, ожидаемый и фактический результат. Укажите модель iPhone, iOS и версию Journal. Перед публикацией скриншота скройте личные заметки.

Для кода создайте ветку от актуального `main` и откройте pull request. Одна задача — одно понятное изменение. Объясните, какое действие пользователя исправляется и как проверили результат. Дождитесь проверок iOS; не публикуйте приложения с секретами, чужими сертификатами и реальными резервными копиями.

Инструкции сборки — в [DEVELOPMENT.md](docs/DEVELOPMENT.md), правила выпусков — в [RELEASING.md](docs/RELEASING.md). Для изменений правил добавляйте тест на наблюдаемое поведение, особенно для дат, лимитов, парсера и восстановления данных. Не добавляйте тесты, просто повторяющие структуру кода.

Следуйте системным паттернам iOS. Не добавляйте веб-оболочку, аналитику, аккаунты и сетевые сервисы без отдельного обсуждения изменения продукта. Предложения функций приветствуются в Issues.

Вклад распространяется по лицензии MIT проекта. Общайтесь уважительно и по существу.
