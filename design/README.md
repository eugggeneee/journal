# Иконка Journal

Силуэт основан на предоставленном пользователем наклонённом колокольчике: мягкая форма, отдельный язычок и короткий изогнутый блик. Новый вариант — тёплый объёмный колокольчик с оранжево-абрикосовым материалом и светлым фарфоровым фоном.

`icon-master.png` — исходный результат встроенного imagegen. `App/Resources/Assets.xcassets/AppIcon.appiconset` — подготовленный RGB-ресурс 1024×1024 без прозрачности и нарисованной внешней маски. Скругление применяет iOS. `AppArtwork` используется в приветствии и настройках. README использует только маленькую копию настоящей иконки.

Способ: встроенный image_gen, не сторонний API или CLI.

## Финальный запрос генерации

Create a finished premium native iOS app icon for Journal, a college schedule app. The attached black bell is the identity reference: preserve its tilted ringing silhouette, rounded lip, separate clapper and short carved highlight, but refine it. One square full-bleed icon; no margins, rounded outer corners, text, badge, frame or mockup. Luminous tangerine/coral/apricot sculptural glass bell, elegant softly rounded volume, warm orange lower edge and restrained honey highlights. Warm ivory porcelain background, minimal soft shadow. Expressive Apple-quality aesthetic, readable at small sizes, simple and inviting. No rainbow, sparkles or clutter. Bell optically centered with generous safe area.
