Как установить за пять минут

Journal ставится файлом из релиза — в магазинах приложений его нет. Выберите свой телефон, дальше всё по шагам.

  1. 1

    Скачайте файл

    Нажмите кнопку — загрузится установочный файл .apk.

    Скачать для Android
  2. 2

    Откройте его

    Файл появится в уведомлении о загрузке и в папке «Загрузки».

  3. 3

    Разрешите установку

    Если Android спросит, разрешите установку из этого источника. Это нужно один раз.

  4. 4

    Откройте Journal

    Выберите свою группу — расписание загрузится само.

Новые версии устанавливаются поверх предыдущей — просто скачайте и откройте свежий файл.

Приложение не подписано Apple, поэтому на iPhone его ставит бесплатная программа-установщик. Подойдёт любая из двух:

AltStoreСам продлевает подпись, пока рядом компьютер с AltServer SideloadlyПроще для разовой установки: перетащили файл — готово
  1. 1

    Скачайте файл

    Нажмите кнопку — загрузится установочный файл .ipa.

    Скачать для iOS
  2. 2

    Подключите iPhone к компьютеру

    Установите AltStore или Sideloadly на компьютер и разрешите доступ на телефоне.

  3. 3

    Установите файл

    В AltStore откройте «Мои приложения» → «+» и выберите .ipa. В Sideloadly перетащите файл в окно, введите Apple ID и нажмите Start.

  4. 4

    Включите доверие

    Настройки → Основные → VPN и управление устройством → доверять профилю. На iOS 16 и новее ещё включите «Режим разработчика» в разделе «Конфиденциальность и безопасность».

С бесплатным Apple ID подпись действует 7 дней — продлевайте её тем же установщиком, чтобы приложение продолжало открываться.

Частые вопросы

Коротко о главном перед установкой.

Это официальное приложение колледжа?
Нет, Journal — неофициальный некоммерческий проект. Расписание берётся с сайта колледжа и может отличаться от актуального, поэтому важные изменения лучше сверять там.
Нужен аккаунт, и сколько это стоит?
Аккаунт не нужен, регистрации и рекламы нет. Приложение бесплатное и некоммерческое.
Что с моими данными?
Оценки, пропуски и настройки хранятся только на вашем телефоне. Единственное, что загружается из интернета, — расписание вашей группы.
Моей группы нет в списке
Введите её номер вручную (3–5 цифр). Если группы нет на сайте колледжа, расписание не загрузится, но оценки и пропуски будут работать как обычно.
Можно открыть данные на другом телефоне?
Автоматической синхронизации нет. Зато есть резервная копия: скопируйте данные в буфер обмена и вставьте на новом устройстве.
Работает ли без интернета?
Да. Уже загруженные дни расписания доступны офлайн, а оценки и пропуски сети не требуют.

Данные хранятся только на вашем устройстве

Оценки, пропуски и настройки остаются в приложении. Из интернета подгружается только расписание группы с сайта колледжа.
