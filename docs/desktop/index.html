      Установка
      шаг за шагом

      Приложение скачивается напрямую, не из магазина. На Android это займёт минуту, на iPhone — минут десять в первый раз.

      1. 1

        Скачайте файл

        Нажмите «Скачать для Android» — файл Journal-…-android.apk сохранится в «Загрузки». Если браузер предупредит, что файл может быть небезопасным, выберите «Всё равно скачать»: так бывает с любыми приложениями не из магазина.

      2. 2

        Откройте скачанный файл

        Нажмите на него в уведомлении о загрузке или найдите в приложении «Файлы» → «Загрузки».

      3. 3

        Разрешите установку

        Android спросит разрешение для браузера или «Файлов». Включите «Разрешить установку из этого источника» и вернитесь назад. Это делается один раз.

      4. 4

        Нажмите «Установить»

        Если Google Play Protect покажет предупреждение о неизвестном разработчике, выберите «Всё равно установить».

      5. 5

        Запустите Journal

        Откройте приложение, выберите свою группу — и расписание сразу появится на экране.

      Обновление

      Скачайте новую версию и установите поверх старой. Оценки, пропуски и настройки сохранятся — приложение подписано постоянным ключом.

      1. 1

        Выберите программу установки

        Приложение для iPhone не подписано Apple, поэтому его ставят через бесплатную программу. Подойдёт любая из двух — способы ниже.

      2. 2

        Установите приложение

        Подключите iPhone к компьютеру, добавьте файл .ipa в программу и войдите своим Apple ID — он нужен только для подписи на вашем устройстве.

      3. 3

        Доверьте профиль

        На iPhone: Настройки → Основные → VPN и управление устройством → ваш Apple ID → «Доверять».

      4. 4

        Включите режим разработчика

        На iOS 16 и новее: Настройки → Конфиденциальность и безопасность → Режим разработчика → включить. Телефон перезагрузится — подтвердите включение.

      5. 5

        Запустите Journal

        Откройте значок на экране, выберите группу и пользуйтесь.

      Два способа установки

      СПОСОБ А · ПРОЩЕ

      Sideloadly

      Нужен компьютер с Windows или Mac и кабель.

      1. Скачайте файл Journal-…-ios.ipa на компьютер (кнопка справа).
      2. Установите Sideloadly для Windows или Mac и запустите.
      3. Подключите iPhone кабелем и нажмите «Доверять» на телефоне.
      4. Перетащите .ipa в окно Sideloadly, введите свой Apple ID и нажмите Start.
      СПОСОБ Б · АВТОПРОДЛЕНИЕ

      AltStore

      Подпись продлевается сама, пока рядом включён компьютер.

      1. Установите AltServer на компьютер с Windows или Mac.
      2. Подключите iPhone и установите через AltServer приложение AltStore.
      3. Откройте на iPhone скачанный .ipa через AltStore — Journal установится.
      4. Пока AltServer запущен рядом, AltStore сам продлевает подпись.

      Частые вопросы

      Это официальное приложение колледжа?

      Нет. Journal — неофициальный некоммерческий проект. Расписание берётся с общедоступной страницы сайта колледжа и может отличаться от актуального — сверяйтесь с официальными объявлениями.

      Сколько это стоит?

      Ничего. Приложение бесплатное, без рекламы и без аккаунтов.

      Нужен ли интернет?

      Только чтобы обновить расписание. Уже загруженные дни (до 400) открываются без интернета, а оценки и пропуски работают всегда.

      Где хранятся мои оценки и пропуски?

      Только на вашем устройстве. Единственный запрос в интернет — загрузка расписания. Аналитики нет.

      Моей группы нет в списке

      Введите номер группы вручную (3–5 цифр). Если группы нет на сайте колледжа, расписание не загрузится, но оценки и пропуски работают как обычно.

      Как перенести данные на новый телефон?

      В профиле сохраните резервную копию в буфер обмена, а на новом устройстве восстановите её оттуда. Копии старого формата тоже подходят. Автосинхронизации между устройствами нет.

      Случайно удалил оценку. Что делать?

      Нажмите «Отменить» на появившейся внизу плашке. Любое добавление, правка и удаление отменяются, поэтому подтверждений нет.

      Это безопасно?

      Исходный код открыт (лицензия MIT). Android-версия подписана постоянным ключом, а в описании каждого релиза есть контрольные суммы для проверки файла.
