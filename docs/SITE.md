# Сайт

Сайт приложения лежит в `site/` и публикуется на GitHub Pages: https://eugggeneee.github.io/journal/. Это статические файлы без сборки и зависимостей: `index.html`, `styles.css`, `app.js`. Файл `palette.js` создаётся скриптом из `lib/core/palette.dart`.

## Правило синхронизации

Изменение кода приложения, которое затрагивает то, что показано на сайте, обновляет сайт в том же коммите. Ждать релиза или отдельной задачи нельзя. Что показано на сайте:

| На сайте | Источник в приложении |
|---|---|
| Темы и их цвета, значки тем | `lib/core/palette.dart`, `assets/icons/preview/` (палитру пересобирает `scripts/site/make_palette.py`) |
| Лимиты пропусков (10 и 72 часа) | `lib/logic/limits.dart` |
| Вкладки и их названия | `lib/ui/app/shell.dart` |
| Экраны в рамке iPhone 16: расписание, оценки, пропуски | `lib/ui/schedule/`, `lib/ui/grades/`, `lib/ui/absences/`, `lib/ui/kit/` и цвета из `lib/ui/kit/foundation/ctx.dart` |
| Список возможностей и тексты | `README.md`, `CHANGELOG.md` |
| Файлы для скачивания и «Что нового» | GitHub Releases (читаются при открытии страницы, правок не требуют) |

Экраны на сайте воспроизводят интерфейс по размерам, скруглениям, цветам и шрифтам из кода: экран 393 x 852 pt, отступы и радиусы из `docs/STYLE.md`. Изменился вид экрана в приложении: поправить разметку этого экрана в `site/app.js` (функции `scheduleScreen`, `gradesScreen`, `absencesScreen`).

`python3 scripts/project/check.py` сверяет сайт с приложением: число тем и палитру, лимиты, названия вкладок, список внешних адресов.

## Правила сайта

- Язык русский, без технических подробностей: только суть и возможности.
- Навигация только сверху, на телефоне и на ПК. Фон сплошной, без прозрачности и размытия.
- Цвета берутся из ролей Material 3 выбранной темы (переменные `--primary`, `--surface` и другие), произвольных HEX в стилях нет.
- Нет эмодзи, внешних шрифтов, счётчиков и сторонних скриптов. Запросы только к `api.github.com`.
- Анимации учитывают `prefers-reduced-motion`.
- Размеры кратны 2, основные шаги 4, 8, 12, 16, 24.

## Сборка и просмотр

```bash
python3 scripts/site/build.py
python3 -m http.server -d build/site 8000
```

Скрипт собирает `build/site`: копирует `site/`, добавляет `docs/logo.png` и значки тем из `assets/icons/preview/`. Папка `build/` в репозиторий не попадает.

## Публикация

Workflow `.github/workflows/site.yml` собирает и публикует сайт при изменении `site/` и связанных файлов в `main`. Один раз в репозитории: Settings, Pages, Source: GitHub Actions.
