# Journal — лендинг (v3.1)

Статический лендинг для приложения **Journal** (МГТЭК · Дневник): Material 3 Expressive, сплошные поверхности без прозрачности, верхняя навигация со скользящим индикатором, карусель экранов в hero, блок «Три вещи» одной карточкой с вкладками (без скролла), интерактивные плитки, подробная установка для Android и iPhone, блок «Последний релиз» из GitHub (с таблицами и кодом из текста релиза), смена палитры (20 цветов). Без сборки и зависимостей.

```
index.html       — выбирает версию: телефон → mobile/, компьютер → desktop/
desktop/         — версия для компьютера (верхняя панель навигации)
mobile/          — версия для телефона (нижняя навигация, жесты, safe-area)
assets/css/      — base.css (токены, компоненты), shapes.css (морфящиеся формы)
assets/js/       — core.js (темы, палитра, виджеты, навигация)
assets/          — мокапы (webp), иконки, og.png
404.html, .nojekyll, robots.txt, sitemap.xml
```

Принудительно открыть версию: `?view=desktop` / `?view=mobile` (запоминается; ссылки есть в подвалах).

## GitHub Pages
1. Сайт уже лежит в папке `docs/` репозитория `eugggeneee/journal`.
2. Settings → Pages → Deploy from a branch → `main` / `/docs`.
3. Сайт: `https://eugggeneee.github.io/journal/`.

## Под себя
- Кнопки «Скачать» ведут на `releases/latest`; замените `href` у `.store` в `desktop/index.html` и `mobile/index.html`, если появятся TestFlight/APK.
- `og:image` и `canonical` рассчитаны на `https://eugggeneee.github.io/journal/`.
- Цвета: `--h` (оттенок) в `assets/css/base.css`; семантические цвета разделов — `.w-sched`, `.w-grades`, `.w-abs`.
- Шрифт Roboto Flex грузится с Google Fonts; без сети — системный.

## Блок «Последний релиз»
Данные берутся из GitHub API (`/repos/eugggeneee/journal/releases`) прямо в браузере посетителя: версия, дата, список изменений
(из текста релиза; поддерживаются заголовки, списки, `feat:`/`fix:`/`perf:`-префиксы и автоматические «What's Changed»), файлы релиза и предыдущие версии.
- Кнопки «Скачать для iOS / Android» автоматически ведут на `.ipa` / `.apk` из последнего релиза (если их нет — на страницу релиза).
- Ответ кешируется на 10 минут (sessionStorage), чтобы не упираться в лимит GitHub API (60 запросов/час на IP).
- Нет релизов или нет сети — показывается аккуратное состояние с кнопкой «Повторить».
- Другой репозиторий: поменяйте `REPO` в `assets/js/core.js`.

## «Три вещи, ради которых открывают дневник»
Вместо стопки карточек (компьютер) и горизонтальной ленты (телефон) — одна карточка и три вкладки.
- Цвет карточки раскрывается кругом от нажатой вкладки; содержимое появляется по очереди.
- Автопоказ: на активной вкладке бежит полоска; любое касание/клик отключает его. При `prefers-reduced-motion` автопоказа нет.
- Телефон: переключение свайпом влево/вправо по карточке; вертикальный скролл страницы не страдает.
- Клавиатура: ← → Home End на вкладках. Длительность автопоказа — `--dur` у `.showcase` (по умолчанию 8s).

## Верхнее меню
- Компьютер: сплошная панель, «пилюля» плавно переезжает на текущий раздел и следует за курсором, внизу — полоса прогресса прокрутки.
- Телефон: панель `position:fixed` на всю ширину экрана, цвет всегда равен фону сайта (`--surface`) — Safari подхватывает его и плавно сливает со страницей. Справа от логотипа появляется плашка с названием текущего раздела.

## Исходники дизайна
Папка `design/` в корне репозитория — полноразмерные исходники для сайта:
- `design/mockups/` — мокапы телефонов (из них получены `docs/assets/phone-*.webp`);
- `design/icons/` — значки и фавиконка (копии лежат в `docs/assets/`);
- `design/social/og.png` — картинка превью ссылки 1200×630 (копия — `docs/assets/og.png`).
На сайт эта папка не влияет: GitHub Pages публикует только `docs/`.
