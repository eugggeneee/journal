Папки `android/` и `ios/` в репозитории не хранятся: их создаёт `flutter create` (локально и в CI).

## Правила данных

- Всё хранится локально в `shared_preferences` одним JSON (версия копии — 2; старые копии с «сокращёнными днями» читаются, лишнее игнорируется).
- Лимиты считаются только по часам **без уважительной причины**: месяц — календарный (с 1-го числа счётчик с нуля), семестр — с 1 сентября до кнопки «Завершить 1-й семестр», затем до 1 августа.
- Звонки: два профиля (`week`, `sat`). Внутри пары может быть перерыв — две половины. «Сокращённый день» — обычная пометка (`DayMark`) на весь день.
- Пометка (`DayMark`): `lesson == 0` — на весь день, иначе номер пары; одна на пару в день.
