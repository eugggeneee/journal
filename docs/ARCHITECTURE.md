# Архитектура

Приложение на Flutter, интерфейс на Material 3 (пакет `material_ui`). Состояние в одном `ChangeNotifier`, данные локальные. Платформенные папки `android/` и `ios/` не хранятся: их создаёт `flutter create` (локально и в CI).

## Слои и правила зависимостей

Направление: `ui` -> `logic` и `data` -> `core`. Папки `data` и `logic` могут импортировать друг друга; `core` не знает об остальных слоях.

| Слой | Может импортировать | Не может |
|---|---|---|
| `core` | только внешние пакеты | `data`, `logic`, `ui` |
| `data` | `core`, `logic` | `ui` |
| `logic` | `core`, `data` | `ui` |
| `ui/kit` | `core`, `data`, `logic`, `ui/app`, `ui/theme` | экраны (`schedule`, `grades`, `absences`, `profile`, `settings`, `onboarding`) |
| экраны | всё, кроме `test` | |
| `lib` | | `test` |

Правила проверяет `scripts/project/check.py` (разбор импортов в `layers.py`; запускается и в CI).


Общие элементы из `components/widgets.dart` сгруппированы в `page_layout.dart`, `badges.dart` и `grouped_cards.dart`. Разделы расписания, пропусков, поведения и данных из `settings_pages.dart` живут в отдельных файлах рядом. Обе точки импорта сохранены для сценария съёмки прежних выпусков. Цветовые роли прежнего `ctx.dart` находятся в `foundation/journal_theme.dart`.

## Данные

- Всё хранится локально в `shared_preferences`: данные пользователя (`data_v1`) и кэш расписания (`sched_v1`, не более 400 дней).
- Резервная копия: JSON с полем `app: journal` и версией формата `version` (сейчас 3); импорт принимает только такие копии.
- Лимиты считаются только по часам без уважительной причины: месяц календарный (с 1-го числа счётчик заново); семестр с 1 сентября до кнопки «Завершить 1-й семестр», затем до 1 августа.
- Звонки: три профиля, `week`, `sat` и `short`. Внутри пары возможен перерыв (две половины). Обед после пары задаётся номером пары. День с пометкой «Сокращённый день» сам идёт по профилю `short` (`AppStore.bellKeyOn`); до первой правки действует шаблон колледжа `kShortDayProfile` (6 пар по часу, перерывы по 10 минут). Готовые расписания называются по времени обеда.
- Пометка (`DayMark`): `lesson == 0` на весь день, иначе номер пары; одна на пару в день.
- Пропуск (`Absence`): одна запись на пару в день; повторное добавление заменяет прежнюю.
- Любая операция с отметками и пропусками отменяема: снимок дня (`snapshotDay`, `restoreDay`) или сохранение прежней записи.

## Расписание

`ScheduleService` загружает страницу `https://bseumtc.by/schedule/public/rasp/PODNAM%20ДД_ММ.htm`, `schedule_parser.dart` разбирает кодировку cp1251 и таблицу группы. `ScheduleRepo` кэширует дни и догружает ближайшие при запуске и возвращении в приложение. Сервис `ReleaseUpdates` отдельно запрашивает последний стабильный релиз на GitHub. Номер релиза и отметка о показанном уведомлении сохраняются локально.

## Интерфейс

- Страницы «Отметки» и «Пропуски» построены на одних компонентах `ui/kit/components/overview.dart`: итоговая карточка, переключатель «Предметы / Журнал», фильтр, карточка предмета, строка журнала.
- Анимации берут длительности и кривые из `ui/kit/animation/motion.dart`. Настройка «Анимации» (выразительные, спокойные, выключены) масштабирует все длительности, системное «Убрать анимации» действует всегда.
- Поверхности плоские: без теней, подъёма и затемнения; границы и уровни задают только цвета `ColorScheme`.
- Вкладки: Главная, Расписание, Отметки, Пропуски. Настройки открываются кнопкой с шестерёнкой в шапке (`settings/settings_home.dart`).
- Главная (`home/`): `day_card.dart` показывает отсчёт до следующего звонка и действия текущей пары. На шкале `day_bar.dart` видны начало и номер пары. Нажатие открывает её карточку. Шапка движется вместе со списком. Область под системными часами принимает цвет видимой поверхности. Шкала дня и три показателя находятся внутри карточки. Их видимость читается из homeHidden, остальные разделы следуют homeOrder.
- Расписание (`schedule/`): `day_timeline.dart` и `week_view.dart` используют `calendar_grid.dart` для часовых линий и отметки текущего времени. В режиме дня интервал может растянуться для длинной записи, в режиме недели время одинаково во всех семи колонках. Карточка `lesson_card.dart` растёт по содержимому. Пары без звонков выводятся отдельным списком. Действия дня доступны в меню выбранной даты в `schedule_page.dart`. В каждом дне `darkerLessons` чередует два нейтральных тона по последовательности предметов. Названия подгрупп сравниваются независимо от порядка, кабинета и преподавателя.
- Задания (`tasks/`): `tasks_page.dart` (список по срочности), `task_tile.dart` (строка с отметкой «сделано», смахивание удаляет), `task_sheet.dart` (форма; открывается и с пары, тогда привязывается к ней). Хранятся в `AppStore.tasks`, напоминают о себе на главной по сроку (без системных уведомлений).
- Отметки: `grades/goal_card.dart` (цель по предмету и прогноз), расчёт в `logic/forecast.dart` (целочисленный, без ошибок округления). Пропуски: `absences/absence_heatmap.dart` (календарь месяца), расчёт в `logic/heatmap.dart`.
- Главная настраивается: порядок и скрытие блоков в `Settings.homeOrder`/`homeHidden`, экран `settings/home_layout_page.dart`. Подсказка о жестах закрывается флагом `Settings.tipGestures`. Неделя сеткой: `schedule/week_view.dart`, на экранах от 720 dp.
- Файлы: `core/file_io.dart` (единственное место, где используются `share_plus` и `file_picker`): резервная копия в .json и восстановление из файла.
- Цвета: `hueTone`, `hueAccent`, `settingHue` в `kit/foundation/journal_theme.dart`: тональные цвета Material 3 для отметок, статусов и значков. Текст не обрезается: длинное переносится или уменьшается.
- Цвета отметок, пропусков и лимитов: `ui/kit/foundation/journal_theme.dart`.

## Платформенная часть

Смена значка: канал `eugggeneee.journal/app_icon`. Нативный код добавляют после `flutter create` скрипты `scripts/icons/setup_android.py` и `scripts/icons/setup_ios.py`; без них приложение работает с обычным значком.
