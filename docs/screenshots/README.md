# Скриншоты Journal

[Открыть последний полный пак](https://github.com/eugggeneee/journal/tree/screenshots/pack) · [Скачать ZIP](https://github.com/eugggeneee/journal/archive/refs/heads/screenshots.zip) · [Запустить сборку](https://github.com/eugggeneee/journal/actions/workflows/screenshots.yml)

В GitHub Actions выберите **Пак скриншотов Journal → Run workflow** на ветке `main`. Процесс сам находит последний стабильный релиз и фиксирует его коммит. Повторный запуск проверяет комплект и контрольные суммы. Если всё уже готово, эмуляторы не запускаются.

В папках `ios` и `android` есть светлая и тёмная темы. Внутри — основные вкладки, предмет, детали пары, формы записей, задания, настройки, профили звонков, приветствие и главная в каждом цвете приложения. Файлы `-raw.webp` содержат исходные пиксели экрана в lossless WebP. В `-framed.webp` тот же снимок помещён в рамку. Модель, среда, версия ОС, разрешение, исходный тег и SHA-256 файлов записаны в `manifest.json`.

На macOS выбирается самый новый базовый iPhone, поддерживаемый установленным симулятором Xcode. На Android используется эмулятор с разрешением Galaxy S26. Он показывает системные элементы Android эмулятора. Рамки рисуются отдельно с металлическим кантом, стеклом, кнопками и вырезом камеры. Ориентиры — [устройства Apple](https://developer.apple.com/design/resources/) и [спецификация Galaxy S26](https://www.samsung.com/uk/business/smartphones/galaxy-s/galaxy-s26-cobalt-violet-256gb-sm-s942bzvgeub/).

Съёмка использует отдельную сборку из исходников релизного тега. Только в ней тест задаёт учебное время, локальное расписание, вымышленные записи и группу **0000**. Кадры берутся через `simctl io screenshot` и `adb screencap`. Новая галерея появляется в ветке `screenshots` одним коммитом после проверки обеих платформ. При ошибке предыдущий пак остаётся доступен.
