# Галереи Journal для iPhone

[Открыть галереи](https://github.com/eugggeneee/journal/tree/screenshots/pack) · [Скачать общий ZIP](https://github.com/eugggeneee/journal/archive/refs/heads/screenshots.zip) · [GitHub Actions](https://github.com/eugggeneee/journal/actions/workflows/screenshots.yml)

## Запуск

В **Actions → Пак скриншотов Journal → Run workflow** выберите ветку `main` и канал.

| Сценарий | Настройки | Результат |
|---|---|---|
| Публикация стабильного релиза в GitHub Releases | Автоматически | Обновляется `pack/stable/` |
| Проверить или восстановить стабильный комплект | `channel=stable` | При совпадении тега, SHA, версии сценария и контрольных сумм съёмка пропускается |
| Снять последнюю опубликованную бету | `channel=beta` | Обновляется `pack/beta/` по самому большому номеру версии и беты |
| Переснять ту же версию | Выберите канал и включите `force_rebuild` | Повторная съёмка выбранного выпуска |

Бета запускается только вручную. Черновики и RC пропускаются. Отсутствие опубликованной беты указано в журнале шага plan.

## Как работает сборка

1. **plan** выбирает релиз, фиксирует тег и SHA и проверяет манифест предыдущего комплекта. При готовом паке шаги capture и publish будут skipped.
2. **capture** готовит отдельный checkout выбранной версии на macOS. Сценарий trade-0000-v1 использует вымышленных преподавателей и группу 0000; учебные предметы сверены с [расписанием МГТЭК за 21 ноября](https://bseumtc.by/schedule/public/rasp/PODNAM%2021_11.htm). Для съёмки зафиксированы 18 ноября 2026 года, 11:10 и iPhone 17 с iOS 26.2. Готовый кадр снимается через simctl после отрисовки виджета. Сбой конкретной сцены ищите в логе capture.
3. **publish** собирает 57 сцен × две темы, включая главную в 20 палитрах, формы, настройки и приветствие. Внутри канала: `ios/light/` и `ios/dark/` с lossless-оригиналами и двумя вариантами прозрачного корпуса. В `frames/` лежат самостоятельные PNG-рамки. В `mockups/` — ход дня, расписание, оценки с пропусками и главная обложка. Всего 348 изображений, README и манифест.
4. Для обложки 1800 × 1200 слева размещается тёмное расписание, в центре — светлый отсчёт, справа — оценки. Над ними иконка выпуска, Journal и слоган «От первой пары до последней оценки». Для краткого анонса — «Пары и оценки под рукой». Проверьте все три силуэта и слоган в превью шириной 360 px.
5. Проверяются имена, количество, разрешение и SHA-256. Перед записью снова сверяется последний тег. Готовый канал заменяется одним коммитом в ветке screenshots. Ошибка оставляет прежний комплект доступным. Повторите workflow после устранения причины.
6. После успешного запуска отдельный workflow «Каталог Journal для iOS» публикует обложку и пять PNG в корпусах. Основной источник использует стабильные кадры. Если совпадающая бета ещё не снята, тестовый источник подписывает стабильные кадры их версией. При проблемах публикации проверьте шаги build и deploy этого workflow.

Модель, версия iOS, SHA приложения, канал, идентификаторы и SHA-256 сценария и фикстуры, разрешение и суммы файлов записаны в manifest.json внутри каждой подпапки.
