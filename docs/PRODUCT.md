# Journal: согласованные решения

## Продукт

- Полностью нативное приложение для iPhone, iOS 18+. Swift, SwiftUI и Swift Charts; без WebView, Flutter и React Native.
- Интерфейс на русском. Название Journal, bundle ID `eugggeneee.journal.app`.
- Три вкладки: Расписание, Оценки, Пропуски. Настройки — отдельная кнопка.
- Только МГТЭК, источник `bseumtc.by`. Одна основная группа; при смене личные данные и архив сохраняются.
- Все варианты занятий и подгрупп видны без отдельного фильтра.
- Нет аккаунтов, рекламы, аналитики, iCloud-синхронизации, виджетов, Live Activity, уведомлений, Siri, отдельного раздела домашних заданий и сайта проекта.
- Чистый старт; импорт старого JSON v2 не включён. Новый формат резервных копий — v3, включая архив расписания.

## Правила

- Оценки 1–10; простое среднее, динамика по последней оценке. Для равных дат порядок определяется временем создания, затем UUID.
- Пропуск: 1 или 2 академических часа, уважительный либо неуважительный. Один пропуск на пару в день; записи без номера пары независимы.
- В лимитах только неуважительные часы. По умолчанию месяц: 10, предупреждение с 7; семестр: 72, предупреждение с 62. Значения редактируются.
- Учебный год: 1 сентября — 1 августа включительно. 2–31 августа — каникулы. Первый семестр завершается пользователем; второй начинается в день действия.
- Пометка: одна на пару или весь день. Пресет «Сокращённый день» относится ко всему дню и переключает профиль звонков.
- Сокращённые звонки с предоставленного объявления 06.11.2026: 08:20–09:20, 09:30–10:30, 10:40–11:40, 11:50–12:50, 13:00–14:00, 14:10–15:10. Внутренние перерывы на объявлении не указаны. Профиль редактируется, применяется по пометке на любую дату.
- Обычные звонки: два будничных пресета и субботний из спецификации. Субботний пресет требует сверки с актуальным объявлением: сайт колледжа при исследовании вернул 403. Это отмечено в интерфейсе, неподтверждённые времена не называются проверенными.

## Данные и сеть

- Календарь и время занятий — Europe/Minsk, независимо от часового пояса телефона.
- URL без года; дата заголовка сверяется с полной запрошенной датой. cp1251/UTF-8, рамки U+2502, наследование пустых ячеек, варианты подгрупп и удаление дублей.
- Воскресенье и каникулы — локальные состояния. Сегодня/будущее: свежесть 20 минут; прошлые сохранённые дни не перезапрашиваются.
- При ошибке сети показывается архив. Предзагрузка: вчера, сегодня и ещё 4 дня; при старте/возврате зависит от автообновления, при явном действии — запускается принудительно.
- По сравнению со старой версией архив не обрезается на 400 днях: прошлое расписание нельзя восстановить с сайта. Полный архив входит в копию.
- Запросы предзагрузки последовательные для уменьшения нагрузки на сайт; одновременная загрузка одного дня дедуплицируется.
- До 20 отмен личных действий в сессии; обновления сетевого архива сами не засоряют историю отмен.

## Визуальный язык

Минималистичный, информативный интерфейс с выразительными тёплыми акцентами, вдохновлённый Apple Music, Numbers и системными приложениями. Системные заголовки, таб-бар, формы, меню, листы, пикеры и стандартные жесты. Карточки содержимого остаются читаемыми; стекло применяется к навигации и управляющим элементам.

Системные цвета и шрифт San Francisco, SF Symbols по смыслу. Светлая/тёмная темы по системе. Dynamic Type, VoiceOver, зоны нажатия от 44 pt. Движение преимущественно системное; нет декоративного параллакса и бесконечных анимаций.

Обязательные источники: приложенные UI UX Pro Max (доступность, SwiftUI) и Emil Kowalski apple-design/write-swift/animate (системные взаимодействия, отзывчивость, сдержанное движение). Веб-рецепты не переносятся в нативное приложение. Автоматическая рекомендация веб-лендинга UI UX Pro Max отклонена как неподходящая продукту.

Основные рекомендации Apple: [Liquid Glass](https://developer.apple.com/documentation/technologyoverviews/adopting-liquid-glass), [Materials](https://developer.apple.com/design/human-interface-guidelines/materials), [Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility).
