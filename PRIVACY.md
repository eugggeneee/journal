# Конфиденциальность

Journal хранит оценки, пропуски, пометки, расписание звонков, настройки и архив расписания в контейнере приложения на iPhone. Journal не создаёт аккаунтов, не содержит рекламы, аналитики и серверной синхронизации.

Единственное автоматическое сетевое действие — загрузка общедоступных страниц расписания по HTTPS с `bseumtc.by`. Страница содержит все группы; фильтрация выбранной группы происходит на устройстве. Оценки, пропуски и пометки на сайт не отправляются. Сайт получает обычные сведения сетевого соединения, в том числе IP-адрес. Cookies не сохраняются.

Внешние ссылки GitHub открываются отдельно по действию пользователя. Journal не опрашивает GitHub для обновлений. Установка и подпись через AltStore обслуживаются отдельным приложением.

Резервная копия создаётся только по вашему действию и содержит весь архив. Файл JSON не зашифрован отдельным паролем: храните его в защищённом месте. Восстановление требует подтверждения. iOS может включать контейнер приложения в системную резервную копию устройства — это определяется настройками iPhone, а не синхронизацией Journal.

Рабочий файл записывается атомарно. Сохраняется предыдущая рабочая версия; повреждённые исходные файлы сохраняются отдельно и могут быть экспортированы из раздела резервной копии. Встроенная защита файлов действует до первой разблокировки после перезагрузки.

Не публикуйте полные резервные копии, персональные заметки или секреты в GitHub Issues. Демонстрационные данные для автоматических скриншотов вымышлены и включаются только в Debug-сборке с отдельным параметром запуска.
